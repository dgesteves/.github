# dgesteves/.github

Default community files for the public repositories of [@dgesteves](https://github.com/dgesteves).

GitHub shows the files here in any repository that has none of its own. Today that is [SUPPORT.md](SUPPORT.md): where to ask, what is supported, how releases and versions work, and how I handle AI-assisted pull requests.

| Project | What it is | Issues | Discussions |
|---|---|---|---|
| [onsystem](https://github.com/dgesteves/onsystem) | Keeps coding agents on your design system | [Issues](https://github.com/dgesteves/onsystem/issues) | [Discussions](https://github.com/dgesteves/onsystem/discussions) |
| [ondocs](https://github.com/dgesteves/ondocs) | Open-source Ask AI for your docs | [Issues](https://github.com/dgesteves/ondocs/issues) | [Discussions](https://github.com/dgesteves/ondocs/discussions) |
| [signoff-ui](https://github.com/dgesteves/signoff-ui) | Review what your agent changed. Approve what it may do | [Issues](https://github.com/dgesteves/signoff-ui/issues) | [Discussions](https://github.com/dgesteves/signoff-ui/discussions) |

Each project keeps its own CONTRIBUTING.md, SECURITY.md, code of conduct and issue forms. Those take precedence over anything here.

Security problems go through each repository's private vulnerability reporting, never a public issue.
